# CodeAlpha Task 3 - Data Visualization

## Project Overview
This project visualizes the Books to Scrape dataset using Python, Pandas, and Matplotlib.

## Visualizations
1. Bar chart: number of books by star rating.
2. Histogram: distribution of book prices.
3. Pie chart: percentage of books by rating.

## Dataset
`books_dataset.csv` contains the book data collected for CodeAlpha Task 1.

## Requirements
Install the required libraries:
```bash
python -m pip install pandas matplotlib
```

## How to Run
Open a terminal in this folder and run:
```bash
python data_visualization.py
```

The script saves graph images into the `visualizations` folder.
